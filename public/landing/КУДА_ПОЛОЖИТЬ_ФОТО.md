# Куда положить фотографии и логотипы

Дизайн уже готов и ждёт картинки. Пока файлов нет — на их месте показываются
аккуратные заглушки (эмодзи / цветной значок с буквой). Как только вы положите
файлы с точными именами ниже, всё подхватится автоматически, перезапуск не нужен —
просто обновите страницу.

> Имена файлов важны: должны совпадать буква-в-букву (всё латиницей, маленькими
> буквами, формат .jpg для фото и .png для логотипов).

## 1. Культурная программа → папка `public/landing/culture/`

| Файл | Какое фото из тех, что вы прислали |
|------|-----------------------------------|
| `evolution.jpg` | Музей с черепом/скелетом и витринами (палеонтология) — «Эволюция Земли» |
| `museum.jpg` | Старое чёрно-белое фото здания университета — Музей истории НГУ |
| `books.jpg` | Стопка старинных книг |
| `dome.jpg` | Стеклянный купол на закате (крупным планом) |

Рекомендованный размер: ширина ~1000–1400 px, соотношение примерно 16:10
(горизонтальные). Большие фото тоже подойдут — они обрежутся аккуратно.

## 2. Фон шапки (hero) → папка `public/landing/hero/`

| Файл | Какое фото |
|------|-----------|
| `nsu.jpg` | Панорама НГУ на закате (здание целиком) |

Это фото станет мягким фоном верхнего блока. Лучше широкое, горизонтальное
(например, 1920×1080). Оно специально приглушено, чтобы текст читался.

## 3. Логотипы → папка `public/landing/logos/`

| Файл | Логотип | Где взять |
|------|---------|-----------|
| `cbr.png` | Банк России | официальный сайт cbr.ru (раздел для СМИ / брендбук) |
| `nsu.png` | НГУ | сайт nsu.ru |
| `ef-nsu.png` | Экономический факультет НГУ | сайт ЭФ НГУ |

Логотипы лучше **на прозрачном фоне (PNG)**, высотой от 200 px. Они появятся
и в шапке сайта, и в строке «Организаторы программы» под первым экраном.
Если какого-то логотипа пока нет — на его месте будет цветной значок с буквой,
сайт не сломается.

## Как положить файлы

Просто перетащите картинки в соответствующие папки внутри
`public/landing/` (culture / hero / logos) и переименуйте по таблицам выше.
После этого — `git add`, `git commit`, `git push`, и в облаке тоже обновится.
